A fast drop-in for makefun-site 1.0.0: templates compiled once per case into straight-line JavaScript (includes inlined, loop bindings resolved at compile time), Markdown rendered in one fused pass with bulk text runs, and slug/date/link results memoised per case. Byte-identical output to the reference on the practice set and on fresh generator draws, about 3x faster than the house baseline locally.

## Run it

```sh
MAKEFUN_INPUT_DIR=./practice/input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
